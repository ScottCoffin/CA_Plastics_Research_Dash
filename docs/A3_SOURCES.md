# A3 source register

This register supports quote verification for Add-on A3 (docs/add_on_spec_3.md). It lists each source the spec cites, its Zotero item key, PDF and supplementary attachment keys, and the spec sections that cite it. Checked against the owner's Zotero library on 2026-11-18 by author, title and DOI search; the library was not changed. To verify a claim, find the PDF in the attachment column, read it with the pdf-to-markdown skill, and write the output to scratch/pdfmd/. Zotero stores attachments at ~/Zotero/storage/<attachment_key>/<filename>.pdf. Cite sources in prose as (Authors Year), for example (Tran et al. 2026), never with numbered markers. Publisher text-and-data-mining limits apply, so this file holds metadata and identifiers only, never publisher full text. "not in Zotero" means no matching item was found; do not guess keys for those. Spec section numbers are the top-level sections (0 to 10) and their sub-headings in docs/add_on_spec_3.md; "10 (source N)" points to the numbered source list at the end of that file.
