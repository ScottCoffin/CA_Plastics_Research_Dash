## How each count is defined

- **Labelled** means `decision_status` is `complete`, the rule used by the review app
  (`progress` in [`src/atlas/gold_label_review.py`](../src/atlas/gold_label_review.py)).
  Adjudication holds have their own line and are not counted as labelled.
- **Split** comes from a join on `work_id` to [`curation/splits_v2.csv`](../curation/splits_v2.csv).
  Leak-check works (`sample_role=leak_test`) form their own bucket, because the split file stores
  them as `split=test`. The `test` row therefore counts only the 75 pool test works.
- **Evaluation set** is the dev and test pool works, 150 in total
  ([ADR-GOLD-EVAL-SET-2026-11-11](../.agent/DECISIONS.md)). Leak-check works are excluded.
- **Gold release** is any `curation/gold_v*` file or any `gold_v*` git tag. `git tag --list 'gold*'`
  returned no tags. `curation/gold_works.csv` and `curation/gold_grants.csv` do not match the
  pattern and are not releases.
- **plastic_related** is counted over labelled rows only. A labelled row with a blank value would
  show as `(blank)`; none occurred (19 + 19 = 38).
