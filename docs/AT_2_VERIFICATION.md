## Method

- Work count: distinct `work_id` values per `institution_ids` entry in `data/processed/normalized/authorships.parquet`, skipping works with `exclude` = true.
- Ranking: CA institutions (`ca_flag` true in `data/processed/normalized/institutions.parquet`) with at least one work, sorted by count descending then inst_id ascending. v31_rank is the 1-based position in that order.
- type_source precedence: owner_override (`config/institution_overrides.csv`), then owner_reviewed (old top-100 list; owner accepted the proposed type), then rule (`atlas_type` in `data/processed/institutions.parquet`). The resolved type must equal the registry type; the build fails otherwise.
- parent_id: the last `lineage` entry in the registry that differs from the institution's own ID; blank when there is none. Lineage order is not consistent in the source, so this is a roll-up hint for review, not a guaranteed immediate parent.
- needs_review: true only for rule-typed institutions in the new top 100. Owner-overridden new entrants are listed in the review CSV for completeness but carry needs_review false.
- Notes written against the old query are dropped; the owner_notes column is blank throughout. No merger or subsidiary notes exist in the data files, so roll-ups rely on the registry lineage alone.
