How the Atlas stays current

Scheduled GitHub Actions jobs run in a two-hour window each morning, UTC (about 2 to 4 a.m. in California in winter). Times below are drawn to scale.

Static by design

No server or database. Data ship as versioned JSON and Parquet files beside the pages.

Open methods

Code, queries and decisions are public on GitHub. Read the methods
