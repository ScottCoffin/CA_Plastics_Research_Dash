## Licence

Natural Earth data is in the public domain (`https://www.naturalearthdata.com/about/terms-of-use/`).
The `world-atlas` and `us-atlas` packages repackage it as TopoJSON. The package licence files
were not re-checked during this build.

## Method

- Projection: Equal Earth (Šavrič, Patterson and Jenny, 2018). The coefficients and the
  viewBox (`0 0 1000 486.7`) are the same as the design prototype
  `.impeccable/sketches/src/build_geo.py`.
- TopoJSON arcs are decoded. Rings are unwrapped across the antimeridian and copied across
  the seam. Rings whose projected box is under 0.6 px in both directions are dropped.
  Antarctica (`010`) is dropped. California is thinned to every third vertex.
- Output keys: `sphere`, `crop`, `w`, `h`, `countries` (each `{id, name, iso_a2, d}`), `ca`,
  `ca_bbox`, `source`, `licence`.
- `iso_a2` comes from a numeric-to-alpha-2 table in the script. It has 173 entries, each checked
  against `pycountry` (173 of 173 matched, no duplicate targets). N. Cyprus, Somaliland and
  Kosovo have no numeric id in the source, so `id` and `iso_a2` are `null` for them.

## Result

- 176 countries, `w` 1000.0, `h` 486.7. Crop `[2.0, 436.7]`. CA bbox
  `[193.3, 93.8, 209.6, 125.1]`.
- Against the prototype `.impeccable/sketches/src/geo/world.json`: the sphere path, the CA path,
  the crop, the bbox, the viewBox and all 176 country paths are identical, in the same order.
- One deliberate difference: the prototype read the UTF-8 TopoJSON with the Windows default code
  page, so `Côte d'Ivoire` was stored as mojibake (`C\xc3\xb4te`). The script decodes UTF-8
  explicitly, so the name is correct.

## Command

```
py -3.14 scripts/build_world_map.py            # first run downloads and pins both inputs
py -3.14 scripts/build_world_map.py --offline  # cache only; never touches the network
```

The pinned SHA-256 digests reject any other file, so an upstream change fails the build instead
of changing the map silently. To update, change the version in the URLs and the digests together,
and record the change here.
