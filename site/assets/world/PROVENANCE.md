# World map provenance (PLAT-2a, Natural Earth I)

`world.json` is generated by `scripts/build_world_map.py`. It draws the landing page's
country shading and the California outline, and the `/explore` map's frame. Do not edit it by hand.

- Output: `site/assets/world/world.json`, 1,136,975 bytes, SHA-256
  `61caed103f6dad48a5d7b6c79e34673af5ebbb3de6cb4d3ecf167abc8ac808f1`.
- Rebuilt 2026-11-24 from the pinned inputs below (Natural Earth I, 1:50m). It replaces the
  Equal Earth, 1:110m build of 2026-11-17.

The raster `site/data/global/world_raster.json` and the explore data `site/data/global/explore.json`
are built from this file and share its frame. They are rebuilt with
`scripts/build_landing_assets.py --raster-only` and `scripts/build_global_explore.py`, which read
`world.json` and make no projection of their own.

Places for the `/explore` search and small-country markers come from a separate index,
`site/data/global/places.json`, built by `scripts/build_places_index.py` from Natural Earth admin-0
(world-atlas countries-50m) and admin-1 10m, and from GeoNames `cities15000` (populated places with
at least 15,000 people). Natural Earth is public domain. GeoNames is CC BY 4.0
(`https://www.geonames.org/`), so the credit must stay with the data.

## Licence

Natural Earth data is in the public domain (`https://www.naturalearthdata.com/about/terms-of-use/`).
The `world-atlas` and `us-atlas` packages repackage it as TopoJSON. The package licence files
were not re-checked during this build.

## Method

- Projection: Natural Earth I (Patterson, 2007), the polynomial of d3's `geoNaturalEarth1`. The
  frame is `0 0 1000 520`, so `w` is 1000 and `h` is 520. Both the Python builder and the
  front end (`framework/src/components/explore.js`, `frameXY`) use this polynomial, and
  `tests/test_ne_projection_alignment.py` checks that the raster and the outlines agree.
- The owner chose Natural Earth I for the shared global map (`docs/AMBASSADORS_SPEC.md`, section 8).
- TopoJSON arcs are decoded. Rings are unwrapped across the antimeridian and copied across
  the seam. Rings whose projected box is under 0.6 px in both directions are dropped.
  Antarctica (`010`) is dropped. California is thinned to every third vertex.
- Output keys: `sphere`, `crop`, `w`, `h`, `countries` (each `{id, name, iso_a2, d}`), `ca`,
  `ca_bbox`, `small`, `source`, `licence`.
- `small` holds one centroid marker `{iso, x, y, lon, lat}` for each country whose projected area
  is under 4 square pixels, so tiny island states stay visible and clickable. Tuvalu has no outline
  in the 50m file, so its marker is set by hand on Funafuti.
- `iso_a2` comes from a numeric-to-alpha-2 table in the script. Countries without a numeric id
  (N. Cyprus, Somaliland, Kosovo) have `id` and `iso_a2` set to `null`.

## Result

- 211 country entries (207 with `iso_a2`, 4 without an id), 64 `small` markers, `w` 1000.0,
  `h` 520.0. Crop `[7.3, 442.0]`. CA bbox `[181.7, 124.6, 200.8, 155.1]`.
- The earlier Equal Earth build had 176 countries, `h` 486.7, crop `[2.0, 436.7]`. It no longer
  matches the design prototype `.impeccable/sketches/src/geo/world.json`, which stays Equal Earth.
- The script decodes the UTF-8 TopoJSON explicitly, so `Côte d'Ivoire` is stored with the correct
  name.

## Command

```
py -3.14 scripts/build_world_map.py            # first run downloads and pins both inputs
py -3.14 scripts/build_world_map.py --offline  # cache only; never touches the network
```

The pinned SHA-256 digests reject any other file, so an upstream change fails the build instead
of changing the map silently. To update, change the version in the URLs and the digests together,
and record the change here.
