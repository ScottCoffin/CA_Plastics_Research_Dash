# MEMORY (durable facts only; <=200 lines)

## Project in one paragraph
CA Plastics Research Atlas is a static public dashboard and reproducible Python
pipeline for California plastic-related expertise, monitoring data, and funding.
The canonical product and implementation contract is `spec.md` v1.0 (2026-11-05).

## How to run (commands)
- Install: `make setup` or `python -m pip install -e ".[dev]"`.
- Test: `make test` or `python -m pytest` (local Windows invocation: Known pitfalls, first bullet).
- Lint: `make lint` or run Ruff check and format-check directly.
- Build bootstrap validation: `make build` or `python -m compileall -q src`.
- OpenAlex smoke: `python scripts/smoke/openalex.py` after editable install.
- ROR smoke: `python scripts/smoke/ror.py` after editable install.
- Build/update institutions: `python scripts/build_institutions.py`; it reads
  `OPENALEX_API_KEY` (or local alias `OPEN_ALEX_API_KEY`) from ignored `.env`.
- S1.2 machine acceptance: `python scripts/check_s1_2.py`; add
  `--require-owner-review` only after all 100 review rows are signed off.
- Build geography: `python scripts/build_geography.py`; use `--land-archive`
  and `--cdfw-archive` for already-downloaded official source archives.
- Geography smoke/acceptance: `python scripts/smoke/geography.py` and
  `python scripts/check_s1_3.py`.
- Gazetteer source smoke/build/acceptance: `python scripts/smoke/geonames.py`,
  `python scripts/build_gazetteer.py`, and `python scripts/check_s1_4.py`.

## Conventions (naming, IDs, paths, timezones: store UTC; CI cron is UTC)
- Python package uses the `src/atlas/` layout and requires Python >=3.11.
- Processed fields and file names use `snake_case`; stable IDs follow `spec.md` C3.
- Store timestamps in UTC; GitHub Actions schedules are UTC.
- Raw/interim data, API logs, full text, secrets, scratch files, and models are ignored.
- Commit only slim processed/site data after upstream license review.
- S3.1 site data is generated by `scripts/build_export_site.py` and documented
  in `docs/SITE_DATA.md`; `site/data/build_metadata.json` records raw/gzip
  sizes and the fixture payload is below the 3 MB gzip C5 target.
- `index.json` contains slim work/author rows, `authors/<author_id>.json`
  contains full work details, and institution summaries/maps plus
  year/type/tag aggregates are separate payloads. Missing labels remain null.
- Each atomic checkpoint completes exactly one dependency-satisfied task. A
  continuous Goal-mode run may seal multiple checkpoints sequentially.

## Verified API facts
- OpenAlex (2026-11-11): boolean title_and_abstract searches cost 10 credits/call and are
  limited to 5 req/s when they have >5 operators (429 "wait 1s"); the client throttles
  and retries that 429. Rejected 429s carry no credit header; the budget guard charges
  them the 10-credit reserve. Every live call must go through the budget guard.
- CORE API v3 (2026-11-11): owner key in `.env` (renewed daily by the owner; remind on 2026-11-12); Bearer auth; 150-token bucket per window; good for full text by DOI and CA place-name phrase searches (theses/grey lit), useless for CA affiliation discovery. See `docs/api_notes/supplementary_sources.md`.
- NSF Award Search (2026-11-10): `api.nsf.gov/services/v1/awards.json`; uppercase OR only; two quoted phrases OR'd silently return 0, so use one phrase per query; `awardeeStateCode`/`perfStateCode`; dates mm/dd/yyyy filter the `date` field; errors can arrive as HTTP 200 with `serviceNotification`. See `docs/api_notes/nsf_awards.md`.
- USAspending (2026-11-10): `spending_by_award` limit ≤ 100; page 101 returns an empty 200 (silent 10k ceiling, so cap and defer); keywords OR-join and substring-match, so bare "plastic"/"polymer" are noisy; key = `generated_internal_id`. See `docs/api_notes/usaspending.md`.
- NIH RePORTER v2 (2026-11-10): keyless POST `/v2/projects/search`; text search needs `operator: advanced`, `search_field: projecttitle,abstracttext,terms` with quoted OR phrases (no stemming); limit ≤ 500; offset ≤ 14,999 (split by fiscal year); `org_states` takes 2-letter codes (a full name silently returns 0). See `docs/api_notes/nih_reporter.md`.
- Regional Water Board layer (EM-2, 2026-11-09): FeatureServer/1 GeoJSON query returns 9 features (`rb` 1-9) in one request. `atlas.geo.rwqcb.assign_region` adds the offshore rule against S1.3 CDFW state waters. ## Known pitfalls (top 10; details in LESSONS.md)
